# LALI — лендинг онлайн-курса по монтажу

Статический сайт курса «Монтаж с нуля до профи»: монтаж Reels и рекламных роликов
на телефоне (CapCut, Alight Motion, нейросети).

## Что внутри

```
index.html          вся разметка страницы
css/styles.css      стили: переменные дизайна, шрифты, интерактив
js/main.js          параллакс облаков, ленивые видео, скролл отзывов, кнопка «наверх»
img/                картинки: герой, облака, иллюстрации, фото автора, отзывы
videos/             4 ролика учениц (mp4, H.264)
fonts/              Forum, Manrope, PT Serif — локально, без обращений к Google Fonts
```

Зависимостей и сборки нет — это обычные файлы, которые открывает любой браузер.

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом тоже можно, но через локальный сервер
корректнее работают шрифты и видео.

## Что можно поменять без программиста

- **Ссылки на связь.** Найти в `index.html` `https://t.me/lalignv` и
  `https://api.whatsapp.com/send/?phone=79290380404` — заменить на свои.
- **Цены.** Они уже в разметке, но скрыты атрибутом `hidden`
  (рядом стоит комментарий «цены: убери hidden, чтобы показать»).
  Убрать `hidden` — цена появится в карточке тарифа.
- **Тексты.** Правятся прямо в `index.html`.
- **Видео и картинки.** Заменить файл в `videos/` или `img/`, сохранив имя.

## Публикация

Репозиторий настроен на GitHub Pages: workflow `.github/workflows/pages.yml`
собирает и публикует сайт при каждом пуше. Чтобы это заработало, в настройках
репозитория нужно один раз включить **Settings → Pages → Source: GitHub Actions**.

## Производительность

- Видео не загружаются, пока не появятся на экране (`data-src` + IntersectionObserver),
  поэтому страница открывается быстро, несмотря на 18 МБ роликов.
- У всех роликов атом `moov` стоит в начале файла — воспроизведение стартует
  до полной загрузки.
- Шрифты лежат локально: нет внешних запросов и зависимости от доступности Google Fonts.
